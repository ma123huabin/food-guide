# 图片目录

| 类型 | 文件夹 | 命名示例 |
| --- | --- | --- |
| 城市封面图 | `城市封面图/` | `北京城市封面图.png` |
| 城市美食地图 | `城市美食地图/` | `泉州城市美食地图.png` |
| 美食图片 | `美食图片/` | `泉州姜母鸭.png` |
| 地图参考图 | `地图参考图/` | 原地图参考文件 |
| 界面参考图 | `界面参考图/` | 首页、详情页参考 |
| 审核预览 | `审核预览/` | 多图审核总览 |

同类型的待审核稿、历史版本、原始图集分别保存在该类型目录的 `待审核/`、`历史版本/`、`原始图集/`。游戏正式使用路径与审核稿路径在 `../assets/data/cities.json` 中分别记录。封面图和美食图已从旧图集中拆为独立图片，后续可按城市和菜名逐张替换。
