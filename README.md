# 美食攻略 · 一城一味

## 首页轮播参数

在 Godot 打开 `scripts/screens/HomeScreen.tscn`，选中根节点 HomeScreen，在检查器的「首页自动轮播」分组调整。默认值定义于 `scripts/screens/HomeScreen.gd` 顶部；场景检查器设置会覆盖脚本默认值。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `autoplay_enabled` | `true` | 首页默认自动轮播开关 |
| `autoplay_interval` | `2.0` 秒 | 每次切换完成后的停留时间，首次进入也等待此时间 |
| `autoplay_transition_duration` | `0.45` 秒 | 单次切换动画时长 |
| `autoplay_resume_delay` | `6.0` 秒 | 手动选择与收藏栏交互后的恢复等待；点击或按住大卡片不暂停轮播 |
| `autoplay_after_draw_delay` | `1.0` 秒 | 抽取、强调和掉落动画全部结束后的轮播恢复等待 |
| `autoplay_direction` | `1` | `1` 下一座，`-1` 上一座 |

轮播在数据表启用的城市间循环，不改变点亮记录；进入详情页暂停，返回首页重新计时。切换采用 Cubic / Ease In Out 缓动。随机点亮仍为 3.5 秒，依次加速 0.45 秒、匀速 0.9 秒、减速 2.15 秒，各阶段衔接速度连续；滚动中的卡片按距离平滑切换中心与侧边比例。

## 城市收集栏与数据管理

新玩家初始显示七张待解锁小卡；抽取大卡后先以金框强调，再缩小落入底部，落地时保存点亮记录并显示城市名称和图片，同时从大卡轮播列表及抽卡池移除该城市。全部集齐后显示完成状态，不重复抽取。旧玩家继续显示已收集城市。超过七张后自动从右向左无缝滚动；进入详情页或鼠标移入收集栏时暂停。点击已点亮小卡直接查看对应城市攻略。

| 参数（HomeScreen 检查器「城市收集栏」） | 默认值 | 作用 |
| --- | --- | --- |
| `collection_drop_duration` | `0.75` 秒 | 大卡缩小落入收集栏的时间 |
| `collection_scroll_speed` | `22.0` 像素/秒 | 收集栏向左移动速度，基于480像素设计宽度 |
| `collection_scroll_delay` | `2.0` 秒 | 进入页面及落地后开始滚动前的停留 |

抽中强调分组的 `winner_highlight_duration` 默认 `0.7` 秒，控制掉落前金框强调的时长。

中奖使用卡片自身的金边光晕、扫光和少量金色粒子，两侧图片保持原亮度。强调结束后，中奖卡片完整离开轮播，沿柔和弧线缩小落入现有收藏卡位；剩余卡片在落地前平滑补位，落地后收藏卡轻微回弹。动效不更换首页图片、边框、字体、字号、文案或布局，也不新增常驻 UI。相关实现为 `HomeScreen.gd`、`CityCard.gd` 与绘制临时光效的 `CityWinnerEffect.gd`。

动效回归：`--script res://tests/draw_motion_qa.gd`，使用独立测试存档，覆盖连续抽取、最后一座城市、无重复入池、侧卡不压暗及掉落后收集。带图形渲染器运行时在 `food-guide-build/draw-motion-*.png` 保存各阶段截图。

城市名称、**城市封面图**、**城市美食地图**、热门美食统一从 `assets/data/cities.json` 加载，维护说明和25城记录表见 [CITY_CATALOG.md](docs/CITY_CATALOG.md)。新增20座城市已配置标志性封面和美食，详情地图预留独立字段、状态为待绘制；行政区核验未接入时禁用打卡。

新增封面图集 `img/城市封面图/原始图集/旅游城市封面原始图集.png` 使用内置 imagegen 生成，按7列3行排列，包含泉州独立封面及20座新增城市。它与详情地图是两种独立资源。

Godot 4.6.2，2D 竖屏互动，设计尺寸 480 × 854，使用 Compatibility 渲染。

## 运行

美食弹窗为竖向自适应卡片，正式图片等比例完整显示，依次展示图片、名称和城区，移除长介绍。城区由 `foods[].urban_district` 读取；缺少正式图片或城区时显示待补充，不自动启用审核稿。主要操作按钮统一为蓝色渐变、银白描边、带高光和阴影的立体胶囊，支持悬停、按下及禁用状态，样式实现于 `scripts/components/TravelButton.gd`。

详情页地图铺满屏幕作为底层，返回、标题、美食面板和打卡按钮固定悬浮在上方。手机单指拖动、双指捏合缩放；电脑鼠标拖动、滚轮缩放。最小缩放始终覆盖全屏，最大为该比例的4倍，平移自动限制在图片边界，防止露白。地图与美食点位一起移动；点击点位仍可查看介绍。尚未绘制地图的城市保持筹备提示，不启用空地图交互。参数位于 `scripts/components/MapViewport.gd`：`maximum_zoom`、`wheel_zoom_factor`。

打开本目录的 `project.godot`，按 F6 运行 Main 场景或按 F5 运行整个项目。

## 两页流程

- 首页点击“随机点亮”，城市卡片横向飞驰约 3.5 秒并减速锁定；优先抽未点亮城市。
- 点亮后再次点击中央城市卡进入详情；底部缩略卡可选择城市，左右划动大卡也可切换。
- 已点亮城市可反复浏览，也可继续点亮其他城市；西安、武汉现已开放抽取。
- 详情页按城市资料提供不定数量的热门美食，卡片可左右滑动浏览；已有地图点位可点击查看美食。新增条目逐项来源和数量见 [FOOD_CATALOG_SOURCES.md](docs/FOOD_CATALOG_SOURCES.md)，未确认地图位置的美食仅在列表展示。
- 宜昌、成都、重庆、广州使用各自的插画与地图；泉州使用独立的山海手绘地图，按原比例完整展示。
- 点亮和成功打卡记录本地保存，重启自动恢复；位置坐标不写入城市足迹存档。

## 真实定位

Windows 版通过系统位置服务异步请求坐标。需要系统“定位服务”和桌面应用位置访问可用；不支持定位的电脑会提示失败，不使用模拟坐标作为真实打卡。

Web 导出运行时通过浏览器 Geolocation 请求位置，需要 HTTPS 或 localhost，以及用户的位置授权。Web 导出所需模板不随本项目提供。

使用随项目内置的 WGS84 城市行政区边界，在本机进行 Polygon / MultiPolygon 包含测试（含孔洞排除），并拒绝超过 3 公里的定位误差。不会将用户坐标发送到地图服务。宜昌覆盖下辖秭归等区域，成都覆盖都江堰等区域，重庆覆盖直辖市各区县；不再使用距市中心的半径来决定能否打卡。定位精度和边界数据简化会影响边缘地带识别。

边界数据来自 [GeoJSON 中国地图数据集](https://geojson.cn/data/atlas/china)，固定使用文档标注为 WGS84 的 1.5.1 版本，相关网址和提取脚本见 `assets/data/BOUNDARY_SOURCE.md`。手绘地图和红点是风味示意，不提供真实店铺坐标或导航。

Windows 打包导出时须将 `*.ps1,*.json` 加入导出预设的非资源文件包含过滤器，并确认字体的分发授权；当前已验证的是编辑器中的项目运行。
