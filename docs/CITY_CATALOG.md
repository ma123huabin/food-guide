# 城市数据记录表

实际数据源：[cities.json](../assets/data/cities.json)。25座城市；城市封面图、城市美食地图、美食图片分别放在 `img/城市封面图/`、`img/城市美食地图/`、`img/美食图片/`。

- `tagline`：大卡片下方城市评语。
- `cover_image`：大卡片、小卡片使用的独立城市封面图。
- `flat_map_image`：正式详情地图；`map_review`：待审核地图与审核状态。
- `foods[].image`：正式美食图；`foods[].image_review`：待审核美食图。待审核稿不自动替换正式资源。
- 替换时先在对应类型目录放入图片，再将图片 `path` 写到正式字段，并更新审核记录。美食名本身包含城市名时不重复前缀。
- `foods` 保存名称、地区、介绍和美食示意位置；`enabled` 控制是否加入城市池。没有行政区边界的城市仍禁用打卡核验。
- 地图为城市景点示意，不用于导航；本批按泉州卡通地图风格绘制，不含大标题及食物插图。

## 美食弹窗城区字段

`foods[].urban_district` 存放城区（例如锦江区、鲤城区），与原 `district` 街区标签分开维护。弹窗按“正式美食图片 → 美食名称 → 所在城区”展示，不再显示长介绍；空字段显示“待补充”。泉州面线糊、肉粽等鲤城美食资料参考[鲤城区政府美食栏目](https://www.qzlc.gov.cn/zjlc/lcfq/shi/)。这里展示的是代表性美食区域，不是具体店铺位置。
