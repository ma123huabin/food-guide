# 城市点亮

详情页主按钮为「点亮城市」。点击后展示应用内定位说明：获取一次当前位置，确认是否位于目标城市，不保存坐标。用户选择「暂不授权」关闭弹窗，继续浏览；选择「同意并定位」后才调用真实定位服务。浏览器按权限状态显示原生授权窗口；Windows 由系统位置服务处理权限，应用内说明不能代替系统授权。

请求期间显示「正在确认你的位置」，主按钮禁用以防重复提交。定位成功后沿用 WGS84 行政区多边形核验，不以距市中心的距离判断。

- 城市范围内：保存足迹，弹窗显示「已点亮 · 城市名」「打卡成功」，点击「继续探索」关闭。底部显示「城市已点亮」，不可重复提交。
- 城市范围外：说明尚未到达目标城市，提供「重新定位」与「稍后再说」。
- 权限拒绝、超时、精度不足或设备定位失败：展示具体原因、开启权限和定位服务的指引，提供重试与退出。
- 尚无行政区数据的城市：说明核验筹备中，不申请位置、不记录成功。

详情页的点亮状态对应位置核验足迹；首页抽取收集状态保持现有规则。位置服务当前支持 Windows 与 Web；其他平台显示不支持原因。

验证：`tests/location_flow_qa.gd` 使用独立存档和注入坐标检查授权前不定位、取消、范围外、定位失败、范围内成功及杭州边界，不触发真实位置请求。
